## Documentation

The developer documentation is only partly usable (as of March 2026) but whenever
infrastructure is touched, content will be extended.

The documentation follows [diataxis](https://diataxis.fr/start-here/).
* **[How-To's](how-to/_how-to)** are sparse and **tutorials** are not used.
* Keeping things concise, most pages are **[references](references/_references)**.
* Specialties on the development approach or tooling are *explained* as
  **[concepts](concepts/_concepts)**.

The developer area also prepares feature and module pages for the user area with content being transferred when the implementation becomes usable. See **[drafts](drafts/_drafts)** for more details on the approach.
